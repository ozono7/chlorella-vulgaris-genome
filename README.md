# Chlorella vulgaris genome — figures code and data

R code and data to regenerate Figures 1, 2a, 3, 4, 5 and S0 of the manuscript "De novo assembly and functional annotation of sequences from a culture identified as Chlorella vulgaris: genetic potential relevant to wastewater bioremediation" (in preparation for submission to the Journal of Genetic Engineering and Biotechnology).

The CSV files contain the values reported in the thesis and the manuscript. Raw reads will be deposited in the Sequence Read Archive (SRA); accession numbers are pending.

For information or additional data, contact the corresponding author: Ruth Elena Soria-Guerra (ruth.soria@uaslp.mx).
